# API reference

Generated by `tools/gen_api_docs.py` from the code (do not edit by hand). Interactive docs: `/docs` (Swagger UI) when the backend runs.
Auth: `Authorization: Bearer <token>` from `POST /auth/login`; cameras/AI services/wearables use `X-Device-Key`; the elder's own screen uses `X-Elder-Code`.
Send `Accept-Language: ar` or `en` to get messages in that language. Caregivers only see people assigned to them; admins see everyone.

## Accelerometer endpoint (wearables)
`POST /sensor/accel` takes `{elderly_id, window: 150 x [x,y,z] in g, fs: 50}`. It answers 503 until a model trained on **real** data is installed (`python ml/export_to_backend.py`); synthetic models are refused unless `ALLOW_SYNTHETIC_ACCEL_MODEL=true` (tests only).

## Errors
400 invalid input, 401 not logged in / wrong key, 403 role not allowed, 404 person not found (or not yours), 503 model not available.
